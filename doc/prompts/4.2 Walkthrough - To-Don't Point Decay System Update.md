# Walkthrough - To-Don't Point Decay System Update

Implemented a new dynamic point decay system for To-Don't that divides total points earned by the number of elapsed days, creating a natural score decay to encourage habit consistency.

## 🛠️ Changes Implemented

### 1. HTML & CSS Updates
- **[index.html](Documents/GitHub/[personal]/todonts/index.html)**:
  - Added a `#points-stats-summary` dashboard container in the **Points Distribution Modal** showing raw *Total Points Earned* and *Total Days Passed*.
  - Updated the modal footnote description to clarify that successes shown in the header is a ratio of points/day that decays over time if boundaries are neglected.
- **[style.css](Documents/GitHub/[personal]/todonts/style.css)**:
  - Added styles for `.points-stats-summary` and `.points-stats-row` to match the existing premium design system.

### 2. Core Logic Updates
- **[app.js](Documents/GitHub/[personal]/todonts/app.js)**:
  - Added `initial_load_date` (ISO string) and `days_passed` (fractional number) to the global `AppState.profile` and `DEFAULT_MARKDOWN` objects.
  - Updated the custom `parseYAML` and `stringifyYAML` functions to parse and serialize the new fields correctly.
  - Implemented the `recalculateDaysPassed()` helper function to update the fractional day count based on local time difference.
  - Updated `loadDataFromMarkdown()` to automatically bootstrap missing profile fields if they are missing when loading existing lists (or importing backups) and save them back to the editor immediately.
  - Updated `updateHeaderStats()` to dynamically calculate the score (total successes divided by days elapsed, minimum 0.0001 days to avoid division by zero) and display it in the header as a fractional value with 2 decimal places. Also updates the Points Distribution Modal stats.
  - Integrated `recalculateDaysPassed()` inside checklist checking/unchecking, day-flips, backup reminders, profile exports, and username change handlers to keep the YAML properties updated in the raw markdown data.

### 3. Documentation Updates
- **[README.md](Documents/GitHub/[personal]/todonts/README.md)**: Updated Key Features to describe successes score division and tracking variables.
- **[guide.md](Documents/GitHub/[personal]/todonts/guide.md)**: Added a "Time-Decay Score Calculation" subsection describing the decay formula and YAML properties.
- **[documentation.md](Documents/GitHub/[personal]/todonts/documentation.md)**: Added `v1.5.0` to the version changelog history detailing the decay score implementation and metadata tracking.
