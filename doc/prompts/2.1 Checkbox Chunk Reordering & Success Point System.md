# Checkbox Chunk Reordering & Success Point System

Implement a context-aware task-reordering system for standard tasks, alongside a gamified, randomized success point system and points info bottom sheet.

## User Review Required

> [!IMPORTANT]
> - Checked standard tasks (`- [x]`) and persistent habits (`- <[x]>`) remain clickable so they can be unchecked, which triggers their respective status reversal. Only daily recurring tasks (`- <<[x]>>`) lock as read-only once checked today.
> - When a standard task is unchecked, it moves back to the active section above the `<hr>` divider. If no checked standard tasks remain in the chunk, the `<hr>` divider is removed.
> - The **Successes** badge in the header will be converted from a static `div` to a clickable `<button>` element. Clicking it slides up a bottom drawer detailing how points are distributed across the different task types.

Add helper function to trigger the floating points element:

```javascript
// Helper: Show floating point success indicator
function showFloatingPoints(points, x, y) {
  const element = document.createElement('div');
  element.className = 'floating-points';
  element.textContent = `+${points} Points!`;
  element.style.left = `${x}px`;
  element.style.top = `${y}px`;
  document.body.appendChild(element);

  element.addEventListener('animationend', () => {
    element.remove();
  });
}
```

## Verification Plan

### State Transition Examples

#### Checking standard tasks:
Given:
```markdown
- [ ] tesk 1
- [ ] task 2
- [ ] task 3 (will be checked)
- <[ ]> task 4
- <[ ]> task 5 (will be checked)
- <<[ ]>> task 6 (will be checked)
- <<[ ]>> task 7
```

When checked:
- `task 3` awards +1 or +2 points and shifts to the bottom under `<hr>`.
- `task 5` awards +1 to +5 points and stays in place.
- `task 6` awards +1 to +9 points, streaks increment, and stays in place.

Result:
```markdown
- [ ] tesk 1
- [ ] task 2
- <[ ]> task 4
- <[x]> task 5
- <<[x]>> task 6 
- <<[ ]>> task 7
<hr>
- [x] task 3
```

#### Unchecking standard tasks:
Given:
```markdown
- [ ] tesk 1
- [ ] task 2
- <[ ]> task 4
- <[x]> task 5
- <<[x]>> task 6 
- <<[ ]>> task 7
<hr>
- [x] task 3 (will be unchecked)
```

When unchecked:
- `task 3` changes to `- [ ] task 3`.
- Moves back above the `<hr>`.
- No points are deducted.
- Since no checked standard tasks remain, the `<hr>` divider is removed.

Result:
```markdown
- [ ] tesk 1
- [ ] task 2
- [ ] task 3
- <[ ]> task 4
- <[x]> task 5
- <<[x]>> task 6 
- <<[ ]>> task 7
```
