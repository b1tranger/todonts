# Walkthrough - Task Auto-Reordering & SW Notifications

We have implemented automatic task reordering by streak priority and set up background notifications inside the service worker. Below is a detailed walkthrough of the updates.

## 🛠️ Changes Implemented

### 1. Task Auto-Reordering by Streak Counts
- Added the following helper functions in [app.js](Documents/GitHub/[personal]/todonts/app.js):
  - `getStreakOfLine(line)`: Resolves a task's streak from `AppState.history`.
  - `sortChunk(chunk)`: Extracts streak-based task lines (daily recurring and persistent habits) and sorts them in **ascending** order of their streak counts (lowest streak at the top/highest priority). Preserves the positions of standard tasks (`- [ ]`) and custom markdown headers/dividers.
  - `reorderCheckboxChunks(lines)`: Parses contiguous checklist blocks and sorts the streak-based tasks inside each block.
- Integrated `reorderCheckboxChunks(lines)` into the checkbox handler `handleCheckboxChange()` in [app.js](Documents/GitHub/[personal]/todonts/app.js), so that sorting occurs instantly whenever a task is checked.

### 2. Service Worker Background Notifications
- Added cache-sharing functions in [app.js](Documents/GitHub/[personal]/todonts/app.js):
  - `updateServiceWorkerNotificationData()`: Gathers active (unchecked) tasks from markdown and saves them into Cache Storage (`todont-notification-cache/notification-state.json`) along with notification timestamps.
  - `pingServiceWorkerNotifications()`: Pings the Service Worker via `postMessage` to check if a notification is due.
- Registered `periodicSync` (tag `todont-background-check`) in [app.js](Documents/GitHub/[personal]/todonts/app.js) to trigger background checks on installed PWAs.
- Updated [sw.js](Documents/GitHub/[personal]/todonts/sw.js):
  - Incremented cache version to `todont-cache-v31`.
  - Added `checkBackgroundNotifications()`: Reads notification data from the shared cache, pings a random active task notification every 6 hours, and pings a summary backlog notification every 24 hours.
  - Added event listeners for `message`, `fetch`, and `periodicsync` to trigger notification checks.

### 3. User Guide & Technical Documentation
- Updated [documentation.md](Documents/GitHub/[personal]/todonts/documentation.md) with `v1.7.0` release notes.
- Updated [guide.md](Documents/GitHub/[personal]/todonts/guide.md) to document the new Balanced Score successes calculation, the auto-reordering behavior, and the background notifications.
