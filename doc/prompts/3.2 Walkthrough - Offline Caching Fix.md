# Walkthrough - Offline Caching Fix

I have resolved the issue preventing `documentation.md` and `guide.md` from loading offline through `render.html`.

## Changes Made

### Caching and Service Worker

#### [sw.js](Documents/GitHub/[personal]/todonts/sw.js)
- **Cache Version Bumped**: Incremented `CACHE_NAME` to `todont-cache-v27` to invalidate existing cache storage and force a refresh of the cached static assets.
- **Pre-cached CDN Resources**: Added all critical third-party CDN scripts, stylesheets, and Font Awesome webfonts to the `ASSETS` list so they are fully cached and available immediately upon installation:
  - Google Fonts CSS
  - GitHub Markdown CSS
  - KaTeX CSS and JS libraries
  - Highlight.js CSS styles and JS library
  - Font Awesome 6.7.2 CSS and webfont formats (`.woff2`)
  - Marked and DOMPurify JS parsing/sanitization libraries
- **Query Parameter Interception**: Modified the `fetch` listener's `caches.match` call to include the `{ ignoreSearch: true }` option. This ensures requests to `render.html?file=guide.md` successfully match the cached `./render.html` asset by ignoring any URL query parameters.
- **Dynamic Caching**: Implemented a dynamic fallback strategy in the `fetch` listener. Any successful `GET` requests (e.g. dynamic Google Fonts, KaTeX font glyphs, or custom markdown files) are saved to the cache on the fly while the user is online, ensuring they remain accessible offline.

#### [render.js](Documents/GitHub/[personal]/todonts/render.js)
- **Standalone PWA Support**: Registered the service worker directly inside `render.js` (on window `load` event) so the application remains fully functional and cached even if the user opens the Markdown viewer directly.

---

### Layouts & Assets

#### [index.html](Documents/GitHub/[personal]/todonts/index.html)
- **Unified CDN Links**: Updated Font Awesome to version `6.7.2` (matching the stylesheet version in `render.html`) to prevent redundant font packages and styles from being cached.

## Verification

### Cache Contents
After installing/activating the updated service worker, the following assets are successfully cached:
1. Local: `index.html`, `style.css`, `app.js`, `manifest.json`, `icon.svg`, `render.html`, `render.js`, `render.css`, `documentation.md`, and `guide.md`.
2. CDNs: Marked parser, DOMPurify, Highlight.js, KaTeX, and Font Awesome 6.7.2 (with webfonts).

### Offline Mode Behaviour
- Entering Chrome DevTools and checking "Offline" in the network configuration blocks all outbound requests.
- Clicking the **User Guide** (`render.html?file=guide.md`) or **Documentation** (`render.html?file=documentation.md`) footer link now successfully loads `render.html` using the cache, loads all script dependencies, and renders the markdown document correctly.
