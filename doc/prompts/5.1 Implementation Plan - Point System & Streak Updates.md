# Implementation Plan - Point System & Streak Updates

This plan outlines the technical changes to resolve the streak tracking issue for persistent tasks, update the Successes score formula, and update the stats display and documentation.

## User Review Required

> [!NOTE]
> - **Persistent Task Streak Behavior**: Streaks for persistent tasks will increment when checked once per day, matching the calendar day checking logic of daily constraints. If a persistent task is checked multiple times within the same day (after its 6-hour cooldown), the streak count will remain at its current value for that day rather than double-incrementing.
> - **Score Formula Change**: The header successes score will be calculated as `(Total Points Earned + total_streaks) / (days_passed + total_tasks)`. This introduces a penalty for having a larger checklist size (denominator) while rewarding consistency via active streaks (numerator).
