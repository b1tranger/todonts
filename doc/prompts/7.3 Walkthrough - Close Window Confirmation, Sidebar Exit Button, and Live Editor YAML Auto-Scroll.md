### Javascript App Logic
- **[app.js](Documents/GitHub/%5Bpersonal%5D/todonts/app.js)**:
  - **Table Colspan & Rowspan Emulation**: Refactored `renderTable()` to build a grid of cell descriptor objects and process horizontal and vertical merges. Cells containing `<<^^>>` are merged with the cell to their left (incrementing `colspan`), and cells containing `<<^>>` are merged with the cell above (incrementing `rowspan`).
  - **Table Parsing & Redundant Column Bug Fix**: Fixed a bug where table rows were separated into individual 1-row tables because `closeActiveBlocks()` was being called on every table row matching `tableMatch`. Also fixed a bug in `parseRowCells` where an empty trailing string (from trailing pipe) was not popped due to short-circuiting on empty string falsiness, causing a redundant column on the right.
  - **YAML Comment Injection**: Enhanced `loadDataFromMarkdown()` to automatically inject `<!-- TASKS START HERE -->` at the start of the body text if it's missing, guaranteeing it is always present right after the closing `---` of the YAML Front Matter.
  - **Interactive Parser Filter**: Updated `compileTextLines()` to filter out and ignore `<!-- TASKS START HERE -->` comment from rendering in the Interactive View.
  - **Close App / Back Interception**: Implemented `initCloseConfirmation()` (wired in `boot()`) to check for PWA mode:
    - If in PWA standalone mode, the Close App button is shown. Clicking it prompts `"Cofirm closing window?"`, sets an `isClosing` flag, and calls `window.close()`.
    - Pushes a sentinel state `{ noBackExitsApp: true }` to browser history. When `popstate` triggers, prompts `"Cofirm closing window?"` to set the `isClosing` flag and close the window, or re-pushes state if cancelled.
    - Adds a `beforeunload` listener to prompt standard browser confirmations during manual window closing/reload, which is bypassed if the programmatic `isClosing` flag is set.
  - **Live Editor Auto-Scroll**: Refactored the `#toggle-editor-btn` click handler to find `<!-- TASKS START HERE -->` in the textarea, dynamically calculate the exact pixel height of the wrapped text before the target line using a temporary mirror div matching the editor's typography and content width, and scroll the editor to this offset. This handles text wrapping on narrow mobile screens perfectly.
  - **Link Previews & Image Parser**: Added `renderLinkPreview()` and integrated it in `parseInlineMarkdown()` to capture `![Alt]\(URL\)` syntax. If the target URL terminates in an image file extension, it renders a clean, responsive embedded image. Otherwise, it compiles a premium link preview card displaying the name/alt, domain name, favicon (using a safe fallback onerror trigger), and a quick action link.
