# Update To-Don't Point/Success System with Time Decay

Update the point system so that the score displayed in the header represents the ratio of total points earned to the total days elapsed since the profile was initialized. A new `initial_load_date` variable and a derived `days_passed` counter will be introduced into the YAML front matter of the user's markdown data to track this. The total points and total elapsed days will also be shown in the Points Distribution Modal.

## User Review Required

> [!IMPORTANT]
> The score displayed as **Successes** in the header will now be a fractional value (e.g. `12.50` or `0.00`) instead of an integer. The raw total successes (points) will now be viewable inside the **Points Distribution** modal.
>
> As days pass, the score will automatically decrease if no new habits are successfully avoided, introducing a natural game-like decay mechanic to encourage consistency.

### Core Logic Updates

#### [MODIFY] [app.js](Documents/GitHub/[personal]/todonts/app.js)
- Update `AppState.profile` to include `initial_load_date: ""` and `days_passed: 0`.
- Update `DEFAULT_MARKDOWN` front matter to include `initial_load_date: "2026-07-09T15:09:39Z"` and `days_passed: 3.0` to match its `global_last_synced` date.
- In `parseYAML`, add support for parsing `initial_load_date` and `days_passed`.
- In `stringifyYAML`, serialize `initial_load_date` and `days_passed` to the front matter block.
- In `loadDataFromMarkdown`:
  - If front matter is bootstrapped from scratch, initialize `initial_load_date` to `new Date().toISOString()` and `days_passed` to `0`.
  - If front matter is loaded but `initial_load_date` or `days_passed` is missing, initialize them, update the YAML string and update `AppState.rawMarkdown` immediately to ensure it's saved.
- In `updateHeaderStats()`:
  - Parse `initial_load_date` from profile data (fall back to current time if invalid or missing).
  - Calculate `daysPassed = (now - initialDate) / (1000 * 60 * 60 * 24)`.
  - Display the calculated score as `(total_successes / Math.max(daysPassed, 0.0001)).toFixed(2)` in `#total-successes-count`.
  - Update `#modal-total-successes` with `AppState.profile.total_successes`.
  - Update `#modal-total-days-passed` with `Math.max(daysPassed, 0).toFixed(2)`.
  - Keep `AppState.profile.days_passed` updated with `parseFloat(daysPassed.toFixed(4))`.
