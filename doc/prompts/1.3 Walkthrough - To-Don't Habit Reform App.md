# Walkthrough - To-Don't Habit Reform App

I have built the single-page local-first "To-Don't" Progressive Web App (PWA) with a dual-pane layout, theme switching engine, offline caching, and custom markdown/YAML front matter tracking.

In addition, the app has been polished with collapsible layout configurations, mobile hamburger navigation, premium vector icons, layout-correcting container styles, documentation pages, and integrated reader themes.

## 🚀 Key Features Built

1. **Bi-directional Live Syncing**:
   - Editing inside the raw Markdown editor automatically updates the interactive UI view in real-time.
   - Checking/unchecking tasks in the UI view updates the markdown text inside the editor instantly without breaking active selection focus or cursor positions.
2. **Three-Tier Task Logic**:
   - Standard task (`- [ ]`): Ordinary checkboxes that strike through on check.
   - Persistent habit (`- <[ ]>`): Circle checkboxes that strike through but remain togglable for future updates.
   - Daily recurring constraint (`- <<[ ]>>`): Glow green checkboxes. Once clicked, they immediately lock (read-only/disabled), increment the total success count, and update streak values.
3. **Flexible Card Separator (`<<hr>>`)**:
   - Blocks of content adjacent to `<<hr>>` (paragraphs, tables, lists) bounded by headings or document edges are wrapped in a modern card layout (`border-radius: 12px`).
   - Supports both leading (`<<hr>>` then text) and trailing (text then `<<hr>>`) syntax arrangements.
4. **Local Day-Flip Reset Engine**:
   - Comparing current clock times against the `global_last_synced` front matter parameter on boot or file import.
   - If a new calendar day is detected, all `- <<[x]>>` tasks are automatically restored to `- <<[ ]>>` and stale streaks are updated to `0`.
5. **Periodic Backup Notifications**:
   - Every 5 minutes, a non-intrusive toast pop-up animates up from the bottom-center of the screen for exactly 5 seconds, reminding users to export their progress and updating the global timestamp.
6. **Collapsible Pane Layout**:
   - The editor pane is hidden by default. A circular right-arrow button sits on the right border of the task pane.
   - Clicking this button toggles/expands the Markdown Editor.
   - When the editor is hidden, the task pane centers itself automatically on desktop with side margins (`max-width: 800px`), resembling a clean focused workspace.
   - **No-Clip Toggle Relocation**: Relocated `#toggle-editor-btn` outside `.pane-left` to be a direct sibling inside `.app-layout`. This structural improvement avoids clipping boundaries on all screen widths.
7. **Responsive Top Bar & Navigation Drawer**:
   - On mobile views, the logo is hidden and only the stats-panel (`Successes` badge and `Username` badge) is kept in the top bar to prevent overflow.
   - Action buttons (Theme Toggle, Import, Export, and PWA Install) are hidden in a drawer menu that slides in from the right when the hamburger button is clicked.
8. **Font Awesome Integration**:
   - All standard unicode emojis (`🏆`, `👤`, `📥`, `📤`, `🌙`/`☀️`, `➔`, `🔥`, and toast status indicators) have been replaced with vector icons from **Font Awesome v6** for a premium, unified appearance.
9. **Themed Markdown Document Viewer**:
   - Modified `render.html` and `render.css` to follow To-Don't's layout colors, typography (`Outfit` and `JetBrains Mono`), and light/dark theme variables.
   - Synchronized the theme toggle `localStorage` settings so that selecting light/dark mode inside the document viewer automatically updates the main app preference.
   - Added website footer status links (`User Guide` & `Documentation`) that dynamically load `guide.md` and `documentation.md` in the reader.

## 💡 How to run locally

1. Open your browser and navigate to the running local server at [http://localhost:8000](http://localhost:8000).
2. The browser will load the page, cache assets, and display the default onboarding To-Don't template!
3. Click **User Guide** or **Documentation** in the bottom status bar footer to open the themed Markdown reader and read the documents!
