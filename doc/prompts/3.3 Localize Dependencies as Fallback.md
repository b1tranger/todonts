# Localize Dependencies as Fallback

To make the app completely resilient to CDN outages and fully offline-capable, we will download and localize all CDN-hosted scripts, styles, and font dependencies. The application will use the CDN version by default, but fallback to the localized copies in a `./dependencies` folder if CDN requests fail. Both CDN and localized copies will be cached in the service worker.

## User Review Required

> [!IMPORTANT]
> - A Node.js download script will be executed to fetch and serialize all library files (Marked, DOMPurify, Highlight.js, KaTeX, Font Awesome, and Google Fonts) into the workspace.
> - The Service Worker version will be bumped to `v28` to register and cache all new local files.

## Proposed Changes

---

### Localizing Library Dependencies

#### [NEW] [download_deps.js](Documents/GitHub/[personal]/todonts/scripts/download_deps.js)
- A Node.js script (using native modules `fs`, `https`, `path`) to download all CDN scripts and stylesheets.
- It will parse Google Fonts and KaTeX stylesheet references, download the corresponding `.woff2` font files, and rewrite their CSS url declarations to point to the local files.
- It will create the `dependencies/` folder in the project root.

---

### Fallback Implementation in HTML

#### [MODIFY] [index.html](Documents/GitHub/[personal]/todonts/index.html)
- Add an `onerror` handler to the Font Awesome stylesheet link to fall back to the localized `./dependencies/font-awesome/css/all.min.css` file.

#### [MODIFY] [render.html](Documents/GitHub/[personal]/todonts/render.html)
- Add `onerror` fallbacks to stylesheet `<link>` tags (Google Fonts, GitHub Markdown CSS, KaTeX CSS, Highlight.js CSS, Font Awesome CSS).
- Add JavaScript-based verification and fallbacks for `<script>` tags:
  - If a script fails (via `onerror` or checking variables like `window.marked`, `window.DOMPurify`, `window.hljs`, `window.katex`, `window.renderMathInElement`), load the localized copy dynamically.

---

### Service Worker Updates

#### [MODIFY] [sw.js](Documents/GitHub/[personal]/todonts/sw.js)
- Add all local files under the `dependencies/` folder to the `ASSETS` pre-cached list.
- Keep the CDN resources in the `ASSETS` list as well, so both versions are cached and offline-ready.
- Increment `CACHE_NAME` to `todont-cache-v28`.

## Verification Plan

### Automated Tests
- None.

### Manual Verification
1. Run the downloader script to populate the `dependencies/` folder.
2. Verify all files are downloaded (CSS, JS, `.woff2` files).
3. Test loading the app offline and online. Verify that CDNs are intercepted and served from cache.
4. Temporarily remove CDN links or simulate CDN failure by blocking CDN hosts in DevTools to verify that the app seamlessly falls back to loading local `./dependencies/*` files.
