# Checkbox Cooldown, Uncheck Restrictions & Notifications

Update the To-Don't app behavior to enforce two new user rules:
1. Checked standard tasks (`- [x]`) cannot be unchecked in the Interactive View (they lock and become read-only, matching recurring daily constraints).
2. Persistent habits (`- <[ ]>`) have a 6-hour cooldown after being checked before they can be checked again.
3. Push notification support will be added using the Web Notifications API to notify users the moment their habit cooldown ends.

## User Review Required

> [!IMPORTANT]
> - **Standard tasks**: Once checked, the checkbox becomes disabled/read-only in the Interactive View. If the user wants to uncheck it, they can still do so manually by editing the markdown text in the Live Editor, which will shift it back to the active section above the divider.
> - **Persistent habits**: Checking a habit records the timestamp in `history`. If unchecked, the checkbox is disabled in the Interactive View, displaying a small lock icon with a countdown (e.g. `Cooldown: 5h 42m`) until 6 hours have passed since the last check.
> - **Cooldown Notifications**: When the app boots, or when a persistent habit is unchecked (which starts a cooldown), the app requests Web Notification permissions and schedules local timers. When the 6-hour cooldown completes, a local push notification triggers: `To-Don't Cooldown Finished: "[Task text]" is ready to be checked again. Stay strong!`.

3. **Persistent Habit Cooldown Tracking & Notification Setup**:
   In `handleCheckboxChange`, record the `last_checked` timestamp for persistent habits when they are checked.
   Add helper functions to manage scheduled push notifications:

```javascript
// Map to track active cooldown timers
const activeCooldownTimers = new Map();

// Helper: Schedule a push notification for when cooldown completes
function scheduleCooldownNotification(taskId, taskText, delayMs) {
  if (activeCooldownTimers.has(taskId)) {
    clearTimeout(activeCooldownTimers.get(taskId));
  }

  const timerId = setTimeout(() => {
    triggerCooldownCompletedNotification(taskText);
    activeCooldownTimers.delete(taskId);
    renderInteractiveView(); // Refresh visual status
  }, delayMs);

  activeCooldownTimers.set(taskId, timerId);
}

// Helper: Trigger the actual Web Notification
function triggerCooldownCompletedNotification(taskText) {
  if (!('Notification' in window)) return;
  if (Notification.permission === 'granted') {
    new Notification("To-Don't Cooldown Finished", {
      body: `"${taskText}" is ready to be checked again. Stay strong!`,
      icon: './icon.svg'
    });
  }
}

// Helper: Scan markdown and initialize cooldown notifications
function initCooldownNotifications() {
  if (!('Notification' in window) || Notification.permission !== 'granted') return;

  const lines = AppState.rawMarkdown.split(/\r?\n/);
  for (let i = 0; i < lines.length; i++) {
    const line = lines[i];
    const persMatch = line.match(/^\s*-\s+<\[([ xX])\]>\s+(.*)$/);
    if (persMatch) {
      const isChecked = persMatch[1].toLowerCase() === 'x';
      const taskText = persMatch[2];
      
      if (!isChecked) {
        const taskId = slugify(taskText);
        const historyItem = AppState.history.find(item => item.id === taskId);
        if (historyItem && historyItem.last_checked) {
          const lastCheckedDate = new Date(historyItem.last_checked);
          const now = new Date();
          const diffMs = now - lastCheckedDate;
          const cooldownMs = 6 * 60 * 60 * 1000;
          if (diffMs < cooldownMs) {
            const delayMs = cooldownMs - diffMs;
            scheduleCooldownNotification(taskId, taskText, delayMs);
          }
        }
      }
    }
  }
}
```
